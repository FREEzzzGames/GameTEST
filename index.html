WatchKey

Бесплатный прототип для назначения установленных приложений на мультимедийные кнопки Android: Play/Pause, следующий и предыдущий трек.

Открыть сборки APK Исходный код

Чтобы скачать APK: откройте успешный запуск Android APK в GitHub Actions и скачайте артефакт WatchKey-debug-apk.

Совместимость с Redmi Watch 5 Active пока не подтверждена. Передача событий зависит от Android и приложения-компаньона часов. Функция «Найти телефон» не переназначается.
